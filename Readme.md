# multifol-payment-system

This Node.js package provides a simple integration with Paystack for handling product creation and generating payment links. It allows you to easily integrate Paystack's payment system into your project.

## Features

- **Create products** on Paystack.
- **Generate Paystack payment links** for transactions.
- **Simplified integration** for a seamless payment experience.

## Installation

To install this package, run the following command:

```bash
npm multifol-payment-system
```
